Обрыв туннеля — и трафик стоит

Kill switch живёт не в приложении, а в Windows Firewall: BLOCK на весь исходящий трафик и ALLOW только туннелю. Даже если убить клиент из диспетчера задач, маршруты и правила откатятся сами.

04Фишки

Фишки, ради которых он написан

Не «ещё один VPN», а инструмент, который думает о сети за тебя.

01

Подписки через туннель

Панель заблокирована провайдером? Не важно: список серверов обновляется через сам VPN.

02

Авто-откат сети

Клиент убили из диспетчера задач — маршруты и файрвол откатятся сами. Интернет не «пропадёт».

03

Мгновенный старт

Нативный Rust без Electron: ~24 МБ на диске и холодный старт быстрее секунды.

04

Массовый пинг

Весь список серверов пингуется параллельно за пару секунд — сразу видно, куда подключаться.

05

Discord Rich Presence

Красивый статус в профиле — или полная тишина. Переключается одним тумблером.

06

Обход античитов

BattlEye, EAC и другие автоматически исключаются из туннеля: они просто не видят VPN.
